# 💰 Expense Tracker

A simple and modern **Expense Tracker** built using **JavaScript**, **Tailwind CSS**, and **Chart.js**.  
The app helps you track your **income, expenses, categories**, and visualize spending patterns using a chart.  
All data is stored locally using **localStorage** so your transactions stay saved even after refreshing.

---

## Live Demo
Live URL: https://mini-expense-tracker-three.vercel.app/

## Features

### Add Transactions  
- Add income or expense with a title, amount, and category.

### Auto Calculations  
- Total Balance  
- Total Income  
- Total Expense  

### Categorized Spending  
- Food  
- Travel  
- Accommodation  
- Shopping  
- Salary  
- Others  

###  Local Storage Support  
- All your data is saved in the browser  
- Reloading the page will not erase your transactions

### Beautiful UI  
- Built using TailwindCSS  
- Modern layout with smooth design  
- Responsive and mobile friendly

### Chart Visualization  
- Category-wise spending chart powered by **Chart.js**
